# Loan Support Agent

Final capstone for the **Cred (Banking & FinTech)** track: a production-minded loan-operations support agent built with LangGraph, ChromaDB, SentenceTransformers, `fastmcp`, and FastAPI.

Everything runs under `MOCK_LLM` with zero API keys and zero network access at inference time.

The brief this repository answers is in [`reference/problem-statement.md`](reference/problem-statement.md).
